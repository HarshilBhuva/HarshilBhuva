## About

I'm a Computer Science student focused on cybersecurity and hands-on security engineering. I enjoy understanding how systems fail, turning observations into repeatable investigations, and building tools that make defensive analysis more structured.

- **Current focus:** Web application security and penetration-testing methodology
- **Security interests:** Threat detection, network security, endpoint security, and infrastructure hardening
- **Engineering interests:** Python automation, modular tooling, event pipelines, and security data analysis
- **Learning through:** Purpose-built labs, CTFs, TryHackMe, and project-driven experimentation
